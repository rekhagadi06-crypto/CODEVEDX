# Utility Usage Prediction Tool

## Description
This is a Machine Learning based console application that predicts electricity bills based on usage hours.

## Features
- Add utility usage data
- View data
- Update existing data
- CSV file handling
- Machine Learning prediction
- Exception handling

## Technologies Used
- Python
- Pandas
- Scikit-learn
